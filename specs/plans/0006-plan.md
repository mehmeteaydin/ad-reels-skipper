- **Risk 1: Unlabeled containers leaking on API < 34 when skipped from `visibleNodes`**:
  - *Context*: Skipping `VisibleNode` creation for blank containers must still enqueue their children (while budgets allow) and recycle the non-root container node in the `finally` block on API < 34.
  - *Recommendation*: Keep child expansion and `finally { if (current !== root) safeRecycle(current) }` completely outside the `!rawText.isNullOrBlank() || !rawDesc.isNullOrBlank()` check, and assert `recycleCalls == 1` on unlabeled `TrackingNode` containers at SDK 33.
- **Risk 2: Organic Reels Binder IPC cost with `MAX_TOTAL_VISITED = 2000`**:
  - *Context*: Restoring `MAX_TOTAL_VISITED = 2000` allows deeper traversal on organic Reels where no ad keyword exists.
  - *Recommendation*: Combine three mitigations: (1) raise `DEFAULT_THROTTLE_INTERVAL_MS` to `180L` (fewer scans/sec than both `0004`'s `150 ms` and `0005`'s `120 ms`), (2) skip `isSelected`/`isClickable`/allocation/tokenization on unlabeled layout containers, and (3) retain pending-skip IPC suppression and early-exit termination on ad match.
