## Risks & open questions
- **Environment (`./scripts/doctor` verdict)**: All step prerequisites met (`ok prerequisite met: ./gradlew -v (steps: test, lint, build)`; `ok profile fast: runnable on this machine`; `ok profile full: runnable on this machine`; `== result: 0 fail, 1 warn ==`).
- **Risk 1: Headless screenshot capture (`S-1`..`S-4`, `B-6`) without emulator or repo bloat**:
  - *Context*: `docs/testing.md` requires `VERIFY` to capture headless screenshots for UI states `S-1`..`S-4` into a temporary directory outside the repository.
  - *Recommendation*: Use Robolectric's built-in `@GraphicsMode(GraphicsMode.Mode.NATIVE)` and `decorView.draw(Canvas(bitmap))` under `composeTestRule.runOnIdle` in `HomeScreenTest.kt` when `-Dskipper.screenshot.dir=/tmp/...` is passed during `VERIFY`.
  - *Rationale*: Renders real Skia/HWUI Compose pixels synchronously on the JVM using the already-cached `android-all-instrumented` SDK without extra third-party plugins, `PixelCopy` Looper stalls, or storing images in the repo.
- **Risk 2: Singleton `DataStore<Preferences>` instance lifecycle across service and activity**:
  - *Context*: Jetpack DataStore forbids multiple active `DataStore` instances for the same file in one process.
  - *Recommendation*: Provide a single process-wide `DataStore<Preferences>` singleton extension on `Context.applicationContext` while allowing tests to inject isolated temporary files/test doubles into `DataStoreSkipperSettingsRepository`, `SkipperAccessibilityService`, and `DashboardViewModel`.
  - *Rationale*: Prevents `IllegalStateException` in production while keeping unit and Robolectric tests fast, isolated, and deterministic.
